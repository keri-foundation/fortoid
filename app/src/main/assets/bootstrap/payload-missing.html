FortWeb payload has not been generated yet.

This Android wrapper no longer commits the full shared web payload into git.

Before running the app, stage the canonical runtime payload with one of these commands:

./sync-payload.sh --package /path/to/fortweb-runtime.zip
./sync-payload.sh --fetch --locked
./sync-payload.sh --fortweb-dir ../fortweb

The producer revision comes from config/fortweb-runtime.json. A local checkout must already be at that locked revision, and the package manifest must match it, or the sync is refused.

The generated output is written to app/src/main/assets/payload/ and stays local.
